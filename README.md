## Current programming principles
- Chest/back frequency: generally allow ~2-3 days of recovery, with heavier and lighter exposures rather than making every session maximal.
- Upper chest is a priority: progress incline barbell/machine/dumbbell work while maintaining flat-bench strength.
- Do not add volume merely to add volume; higher-frequency training requires some shorter sessions.
- Lower body receives work through dedicated leg days plus PT, cleans, SLDLs, classes/spin, squats and lunges.
- Future dedicated leg sessions can emphasize supported unilateral work (e.g. single-leg RDLs, split squats/reverse lunges) with moderate loads and controlled tempo.
- Slow eccentrics are a recurring tool, especially for accessory work.
- Swimming emphasis: monofin technique, core/trunk integration and cardiovascular conditioning first; conventional lap volume/speed can build gradually.
